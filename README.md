## AI 구독에 강의 정리 구독까지

클로바노트·다글로 같은 서비스로 강의를 정리하다 보면 무료 제공량을 넘겨 쓰기 위해 별도 구독을 고민하게 됩니다. **Codex나 Claude에 이미 구독료를 내고 있는데, 강의 정리를 위해 구독을 하나 더 추가하는 셈입니다.**

둥둥이는 이 작업에 **내 Mac과 기존 AI(ChatGPT 또는 Claude) 구독**을 사용합니다. 음성은 Mac에서 텍스트로 바꾸고, 문장 교정과 요약은 구독 중인 AI가 처리합니다. 별도 전사 서비스 이용권 없이 강의를 정리할 수 있습니다.

파일을 변환한 뒤 AI 채팅창에 복사하는 과정도 앱에서 처리합니다. 녹음을 마치면 텍스트와 핵심 요약이 같은 기록에 저장되고, 원래 음성과 함께 다시 볼 수 있습니다.

![과목별 녹음과 강의 텍스트를 함께 보여 주는 둥둥이](assets/readme/product-overview.png)

## 녹음한 강의로 복습하는 방법

### 1. 녹음을 마치면 강의 내용이 글로 정리됩니다

**새 녹음**에서 과목 폴더를 고르고 녹음을 시작합니다. 녹음을 마치면 저장된 파일 전체를 텍스트로 변환하고, AI가 문장을 교정하고 강의 제목을 붙입니다. 휴대폰 등으로 녹음해 둔 파일을 가져와도 됩니다.

### 2. 글을 읽다가 궁금한 문장을 누르면 다시 들을 수 있습니다

강의를 재생하면 음악 앱의 가사처럼 현재 문장이 강조됩니다. 문장을 누르면 그 설명이 나오는 시점부터 재생합니다. 이해가 안 된 구간은 반복하고, 다시 볼 곳에는 북마크를 남길 수 있습니다.

예를 들어 전사문에서 ‘가격탄력성’을 찾아 해당 문장을 누르면, 교수님이 그 개념을 설명하던 부분을 다시 들을 수 있습니다.

### 3. 강조한 내용은 요약 카드에서 확인합니다

AI가 전사문에서 중요하다고 언급하거나 반복한 설명을 찾아 **핵심 요약** 카드로 정리합니다. 카드에는 요약과 근거 문장이 연결됩니다. 요약만으로 이해가 안 되면 **해당 구간 듣기**로 원래 설명을 확인할 수 있습니다.

![핵심 요약 카드의 설명과 해당 구간 듣기 버튼](assets/readme/app-summary.png)

_소개용 가상 데이터입니다. 강조 여부는 전사문을 바탕으로 판단합니다._

### 기록은 과목 폴더에 함께 보관합니다

음성·텍스트·요약·메모가 하나의 기록으로 저장됩니다. 왼쪽 폴더를 펼쳐 녹음 목록을 보고, 다른 과목으로 옮길 때는 드래그하면 됩니다. 필요한 내용은 검색하고, 정리한 텍스트는 TXT·SRT·JSON으로 내보낼 수 있습니다.

## 어떻게 다운받나요?

아래 프롬프트를 Mac에서 실행 중인 Codex에 붙여넣으세요. 소스 다운로드와 필요한 도구 설치부터 앱 빌드까지 요청할 수 있습니다.

macOS 14 이상이 필요하며 Apple Silicon Mac을 중심으로 개발했습니다. 현재는 소스 빌드 방식이고, 처음 설치할 때 음성 인식 모델 약 1.62 GB를 내려받습니다.

```text
내 Mac에 ‘둥둥이’를 설치해 줘.
GitHub 저장소: doongdoong-ai/doongdoong

README와 설치 스크립트를 먼저 읽고, 저장소라면 새 폴더에 내려받아 줘.
소스에 접근할 수 없으면 올바른 위치를 물어봐 줘.
macOS 14 이상, Swift 6 도구 체인, Xcode Command Line Tools,
Homebrew, whisper-cli, FFmpeg를 확인하고 부족한 도구만 설치해 줘.
Codex CLI의 ChatGPT 로그인은 내가 직접 하도록 안내하고 API 키 결제로 전환하지 마.
프로젝트 루트에서 ./scripts/setup-engine.sh와 ./scripts/build-app.sh를 실행해 줘.
dist/둥둥이.app을 ~/Applications에 설치하되 기존 녹음·설정은 보존해 줘.
기존 앱이 실행 중이면 종료·교체 전에 알려 주고, 교체할 앱은 백업해 줘.
완료하면 앱을 백그라운드로 열고 설치 위치를 알려 줘.
테스트나 마이크 녹음, AI 전사는 실행하지 마.
```

설치 후 **도움말 → 샘플 녹음으로 둘러보기**에서 사용해 볼 수 있습니다. 샘플은 별도의 AI 처리 없이 열립니다.

녹음은 **새 녹음 → 과목 폴더 선택 → 녹음 시작** 순서로 진행합니다.

<details>
<summary>직접 빌드하기</summary>

Swift 6 도구 체인, Homebrew와 로그인된 Codex CLI가 준비된 상태에서 실행합니다.

```sh
brew install whisper-cpp ffmpeg
./scripts/setup-engine.sh
./scripts/build-app.sh
open -g "dist/둥둥이.app"
```

현재 빌드는 개발용 ad-hoc 서명을 사용합니다. 외부 배포용 서명·공증된 설치 파일은 아직 제공하지 않습니다.

</details>

<details>
<summary>데이터 보관과 현재 지원 범위</summary>

현재 버전은 로컬 Whisper 모델과 ChatGPT 계정으로 로그인한 Codex CLI를 사용합니다. Claude 등 다른 AI 서비스 연결은 아직 지원하지 않습니다.

음성 파일은 Mac에 보관하며, 교정·요약에 필요한 텍스트는 OpenAI로 전송됩니다. 로컬 처리에는 Mac의 연산 시간과 저장 공간이 필요하고, 교정·요약에는 Codex 사용량 제한이 적용됩니다.

녹음과 정리 결과의 기본 위치는 `~/Music/둥둥이`입니다. 기존 라이브러리가 있으면 이어 사용합니다.

음성 인식과 요약에는 오류가 있을 수 있습니다. 중요한 용어·이름·숫자는 원래 음성으로 확인하세요. 자동 번역, 화자 분리, 시스템 오디오 직접 녹음, 강의자료 분석은 현재 지원하지 않습니다.

</details>
