<h1 align="center">둥둥이</h1>
<p align="center"><strong>AI 기반의 대학교 강의 녹음 macOS 앱</strong></p>

## AI 구독에 강의 정리 구독까지

클로바노트·다글로 같은 서비스로 강의를 정리하다 보면 무료 제공량을 넘겨 쓰기 위해 별도 구독을 고민하게 됩니다. **Codex나 Claude에 이미 구독료를 내고 있는데, 강의 정리를 위해 구독을 하나 더 추가하는 셈입니다.**

둥둥이는 **내 Mac의 녹음 앱에 기존 Codex를 연결하는 오픈소스 프로젝트**입니다. 강의를 녹음하면 텍스트와 핵심 요약이 같은 기록에 쌓이고, 문장을 클릭해 그 설명을 다시 들을 수 있습니다. 파일을 변환하고 AI 채팅창에 붙여넣는 과정도 앱에서 처리합니다.

**녹음과 결과는 Mac에 보관하고, 음성 인식과 교정·요약은 OpenAI 서버에서 처리합니다.** 인터넷 연결과 ChatGPT로 로그인한 Codex CLI가 필요합니다.

![과목별 녹음과 강의 텍스트를 함께 보여 주는 둥둥이](assets/readme/product-overview.png)

_화면은 앱의 실제 UI이며, 강의 내용은 소개용 가상 데이터입니다._

## 어떻게 동작하나요?

**녹음 → 5분 단위 파일 전사 → 문장별 시간 맞추기 → 강의 전체 교정·요약 → 복습**

| 단계 | 처리 위치 | 하는 일 |
|---|---|---|
| 녹음·파일 준비 | 내 Mac | 원본을 저장하면서 최대 5분씩 완성된 구간을 나눕니다. 이미 녹음한 파일을 가져와도 같은 방식으로 처리합니다. |
| 음성 → 텍스트 | OpenAI 받아쓰기 서버 | Codex가 앱의 전사 도구를 호출하면, 앱이 구간별 압축 음성 파일을 전송하고 응답을 저장합니다. |
| 따라읽기 시간 맞추기 | 내 Mac | 음성과 전사문을 대조해 각 문장의 재생 위치를 찾습니다. MMS 음향 모델과 강제 정렬을 사용합니다. |
| 전체 교정·제목·핵심 요약 | Codex · GPT-6.1 Sol, medium | 녹음이 끝나면 전체 전사문 맥락을 바탕으로 오류를 검토하고 제목과 근거가 연결된 요약 카드를 만듭니다. |
| 보관·재생 | 내 Mac | 원본 음성, 교정 전후 텍스트, 요약, 메모를 한 기록으로 보관합니다. |

**Sol은 음성 인식 모델이 아닙니다.** 파일 전사를 요청하고 전사된 텍스트를 정리합니다. 음성 인식은 별도의 받아쓰기 서버가 맡으며, 그 서버의 정확한 모델명은 공개적으로 확인되지 않았습니다. Mac의 정렬 모델은 이미 만들어진 텍스트에 재생 시간을 붙이는 역할입니다.

녹음 중에는 완성된 구간부터 전송하고, 종료 후 마지막 구간을 처리합니다. 성공한 응답은 저장해 재시도할 때 재사용합니다. 네트워크 오류가 나도 녹음은 계속 저장되며, 다시 처리하면 남은 구간부터 이어갑니다.

교정은 원래 의미·말투·숫자·반복 표현을 보존하도록 제한합니다. 앱은 문장 ID와 인용 근거, 수정 범위를 검증하고 원문도 함께 보관합니다. 위치가 불확실한 문장은 **‘약’**으로 표시해 자동 따라읽기에서 제외하고, 누락이 의심되는 구간은 직접 듣고 확인할 수 있게 남깁니다.

### 연결과 비용

교정·요약은 ChatGPT 로그인으로 Codex 구독 사용량을 사용합니다. 앱은 API 키 결제로 전환하거나 추가 크레딧을 구매하지 않습니다. 계정에 별도로 구매한 크레딧이 있으면 구독 한도 이후 사용에 적용될 수 있습니다.

음성 전사는 ChatGPT의 **비공식 내부 받아쓰기 경로**를 사용합니다. 이 경로의 과금·한도 규칙은 확인되지 않았으므로 **전 과정의 추가 비용이 없다고 보장하지 않습니다.** 서버나 계정 권한이 바뀌면 전사가 중단될 수도 있습니다. 구현과 확인된 범위는 [기술 문서](docs/technical-guide.ko.md)에 정리했습니다.

## 녹음한 강의로 복습하기

### 글을 읽다가 그 설명을 다시 듣기

강의를 재생하면 음악 앱의 가사처럼 현재 문장이 강조됩니다. 문장을 클릭하면 그 설명이 나오는 시점부터 재생합니다. 본문을 드래그하면 여러 문장에 걸쳐 선택하고 복사할 수 있습니다. 이해가 안 된 구간은 반복하고, 다시 볼 곳에는 북마크를 남길 수 있습니다.

예를 들어 전사문에서 ‘가격탄력성’을 찾아 해당 문장을 클릭하면, 교수님이 그 개념을 설명하던 부분을 다시 들을 수 있습니다.

### 강조한 내용은 핵심 요약에서 확인하기

AI가 전사문에서 중요하다고 언급하거나 반복한 설명을 찾아 **핵심 요약** 카드로 정리합니다. 카드에는 요약과 근거 문장이 연결됩니다. 필요한 내용은 선택해서 복사하거나, 카드별·전체 복사 버튼으로 가져갈 수 있습니다. 요약만으로 이해가 안 되면 **해당 구간 듣기**로 원래 설명을 확인할 수 있습니다.

![핵심 요약 카드의 설명과 해당 구간 듣기 버튼](assets/readme/app-summary.png)

_소개용 가상 데이터입니다. 강조 여부는 전사문을 바탕으로 판단합니다._

### 과목별로 모으고, 필요한 내용 가져가기

**새 녹음**에서 과목 폴더를 고르고 시작합니다. 왼쪽 폴더를 펼치면 녹음 목록이 나오고, 다른 과목으로 옮길 때는 드래그하면 됩니다. 제목은 AI가 붙인 뒤 직접 수정할 수 있습니다. 필요한 내용은 검색하고, 정리한 텍스트는 TXT·SRT·JSON으로 내보낼 수 있습니다.

## 어떻게 다운받나요?

아래 프롬프트를 Mac에서 실행 중인 Codex에 붙여넣으세요. 소스 다운로드와 필요한 도구 설치부터 앱 빌드까지 요청할 수 있습니다.

macOS 14 이상이 필요하며 Apple Silicon Mac을 중심으로 개발했습니다. 현재는 소스 빌드 방식이고, 처음 설치할 때 따라읽기용 시간 정렬 모델과 실행 환경을 내려받습니다.

```text
내 Mac에 ‘둥둥이’를 설치해 줘.
GitHub 저장소: doongdoong-ai/doongdoong

README와 설치 스크립트를 먼저 읽어 줘. 이미 내려받은 프로젝트가 없으면
위 저장소를 새 폴더에 내려받아 줘.
소스에 접근할 수 없으면 올바른 위치를 물어봐 줘.
macOS 14 이상, Swift 6 도구 체인, Xcode Command Line Tools,
Homebrew, Python 3.13, FFmpeg를 확인하고 부족한 도구만 설치해 줘.
설치 과정에서 내려받는 MMS 시간 정렬 모델의 CC BY-NC 4.0 라이선스도 안내해 줘.
Codex CLI의 ChatGPT 로그인은 내가 직접 하도록 안내하고 API 키 결제로 전환하지 마.
프로젝트 루트에서 ./scripts/setup-engine.sh와 ./scripts/build-app.sh를 실행해 줘.
dist/둥둥이.app을 ~/Applications에 설치하되 기존 녹음·설정은 보존해 줘.
기존 앱이 실행 중이면 종료·교체 전에 알려 주고, 교체할 앱은 백업해 줘.
완료하면 앱을 백그라운드로 열고 설치 위치를 알려 줘.
테스트나 마이크 녹음, AI 전사는 실행하지 마.
```

설치 후 **도움말 → 샘플 녹음으로 둘러보기**에서 사용해 볼 수 있습니다. 샘플은 별도의 AI 처리 없이 열립니다.

녹음은 **새 녹음 → 과목 폴더 선택 → 녹음 시작** 순서로 진행합니다.

<summary>직접 빌드하기</summary>

Swift 6 도구 체인, Homebrew와 로그인된 Codex CLI가 준비된 상태에서 실행합니다.

```sh
brew install python@3.13 ffmpeg
./scripts/setup-engine.sh
./scripts/build-app.sh
open -g "dist/둥둥이.app"
```

현재 빌드는 개발용 ad-hoc 서명을 사용합니다. 외부 배포용 서명·공증된 설치 파일은 아직 제공하지 않습니다.

현재는 개인용 베타 수준입니다. 실제 73분 녹음으로 전체 처리와 저장·재생을 확인했지만, 전문용어나 짧은 시험 안내를 잘못 인식하는 경우가 남아 있습니다. 시간 정렬이 성공했다고 내용까지 정확한 것은 아닙니다. 검증 방법과 한계는 [현재 검증 기록](docs/validation-codex-file-transcription.ko.md)을 참고하세요.

자동 번역, 화자 분리, 시스템 오디오 직접 녹음, 강의자료 분석은 현재 지원하지 않습니다.
