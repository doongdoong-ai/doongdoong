# README 제품 이미지 제작 기록

제작일: 2026-10-18. 현재 빌드의 SwiftUI 화면을 앱의 `--snapshot` 기능으로 캡처했다. 개인 라이브러리 대신 `.local/readme-captures` 아래 독립된 샘플 라이브러리를 사용했다. 화면을 활성화하거나 마이크를 켜지 않았고 AI 요청·전사·앱 테스트를 실행하지 않았다.

| 파일 | 내용 |
|---|---|
| `app-reading.png` | 실제 따라 읽기 UI, 2560 × 1640 |
| `app-summary.png` | 실제 핵심 요약 UI, 2560 × 1640 |
| `product-overview.png` | 따라 읽기 캡처에 여백·배경·그림자만 적용한 소개 이미지, 2800 × 1880 |

경제학개론 제목·전사문·강조 카드는 화면 소개를 위해 직접 작성한 가상 데이터다. 실제 수업이나 AI 분석 결과가 아니다. 샘플의 27초 파형은 앱에 포함된 데모 음성을 사용했으며, 화면의 가상 강의와 일치하는 녹음으로 주장하지 않는다. 캡처에는 UI가 표시한 내용을 그대로 담았고 이미지 생성으로 화면을 재구성하지 않았다.

소개 이미지의 여백은 `scripts/render-readme-hero.swift`에서 수정할 수 있다. 저장소 루트에서 `swift scripts/render-readme-hero.swift`로 다시 만든다. 실제 화면 캡처 원본은 별도 PNG로 보존한다.

기존 추상 일러스트는 README에서 제외했다. 기존 앱 로고의 형태는 변경하지 않았다.
