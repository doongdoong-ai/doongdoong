# 둥둥이의 단계별 성능 평가

둥둥이는 음성을 전사하고, 전사문을 교정하고, 교수의 강조 내용을 추출한다. 최종 문장만 비교하면 어느 단계가 좋아졌는지 알 수 없으므로 **ASR 원본·교정 결과·강조 카드·처리 시간**을 각각 보존한다.

## 비교 단위

| 실험 | 고정할 조건 | 확인할 결과 |
|---|---|---|
| ASR 비교 | 동일 음성·구간, 언어, 입력 형식 | 원본 전사, 누락·환각, 숫자·부정·용어, 타임스탬프 |
| 교정 모델 비교 | 동일 ASR 원문·문장 ID·프롬프트·출력 계약 | 필요한 오류 수정, 보호 내용 보존, 부적절한 제안과 적용 여부 |
| 강조 분석 비교 | 동일 텍스트와 근거 규칙 | 실제 강조 포착, 가짜 강조, 인용 근거, 시험 포함·제외 보존 |
| 최종 제품 비교 | 동일 음성, 캐시·재시도·장비 상태 명시 | 실제 대기 시간, 실패·복구, 따라읽기, 최종 품질 |

모든 단계에서 모델·양자화·런타임·프롬프트 버전과 입력·출력 해시를 남긴다. 실행 도중 설정을 바꾸면 다른 실행 ID를 부여한다. 실패·중단·부분 완료도 지우지 않는다.

## 정답과 비교 대상은 다르다

CLOVA Note와 같은 다른 서비스의 결과는 비교 대상이다. 음성을 사람이 확인한 정답 전사문이 아니라면 두 텍스트 사이의 거리를 **문자 불일치율**이라고 표시한다. 이를 CER이나 정확도로 표현하지 않는다.

CER은 정답 문장의 문자 수를 분모로 하고 치환·삭제·삽입 오류 수를 분자로 한다. Unicode 정규화, 띄어쓰기·문장부호 포함 여부를 함께 기록한다. FLEURS 같은 공개 데이터의 제공 정답도 실제 강의의 잡음·긴 맥락·전문 용어를 대표하지 않는다. 작은 표본의 점수 차이로 모델 전체의 우열을 확정하지 않는다.

교정에서는 수정할 필요가 있는 문장의 성공률과 그대로 두어야 하는 문장의 보존률을 나눈다. 모든 문장을 그대로 돌려주는 모델은 보존률은 높아도 교정 목적을 달성하지 못한다. JSON Schema에 맞는 응답과 올바른 내용도 별도로 평가한다.

## 강의에서 특히 확인할 오류

- “시험에 나온다/안 나온다”, “흑자/적자”처럼 방향을 바꾸는 오류.
- 연도·금액·비율·부호·사람 이름의 변형과 자기 정정 삭제.
- 실제 반복을 중복으로 오판하여 삭제하는 경우, 무음에 문장을 생성하는 경우.
- 전문 용어를 외부 지식으로 추정하여 서로 다른 개념을 합치는 경우.
- 끝부분이나 분할 경계의 누락, 잘린 말을 추측하여 완성하는 경우.
- 인용문 안의 “중요”를 교수의 강조로 해석하는 경우.
- 인용이 실제 원문에 있어도 요약의 주장이 그 인용으로 뒷받침되지 않는 경우.

제품 검증기는 ID·문자열·숫자·편집 범위·인용의 존재 등을 검사하지만 모든 의미 왜곡을 판별하지는 못한다. 정성 검토에서 발견한 오류는 구체적인 입력·출력과 함께 보존한다.

## 시간과 메모리 측정

모델 다운로드·첫 로딩·음성 정규화·ASR·교정·요약·정렬·재시도·저장을 분리한다. 캐시가 있는 실행과 없는 실행, 전체 파일과 일부 구간을 구분한다. 일부 구간의 처리율로 계산한 전체 예상 시간에는 **추정**이라고 표시한다.

녹음 중 증분 처리는 녹음 종료 뒤 대기 시간을 줄이는 설계다. 전체 연산 시간이 같은 비율로 줄었다고 해석하지 않는다. 모델 상주 여부와 실제 로딩 횟수를 별도로 확인한다.

Apple Silicon의 프로세스 RSS는 전체 통합 메모리·Metal 할당량과 같지 않다. 측정 방법·샘플 간격·AC/배터리 상태를 명시한다. 8GB 장비에서 Whisper와 텍스트 LLM을 함께 사용할 경우 순차 로드와 메모리 반환을 별도로 검증해야 한다.

## 보관 형식

로컬 평가 자료는 `.local/`에 둔다. 실행 기록에는 최소한 다음 정보를 포함한다.

```text
run ID / 날짜 / 완료·실패·부분 완료 상태
소스 코드 revision / 모델 원본·변환본 revision / 가중치 SHA-256
장비·OS·런타임·전원 / 분할·언어·VAD·샘플링 설정
입력 해시 / 프롬프트·스키마 / 원본 응답 / 검증 결과
시간의 포함 범위 / 캐시·재시도 / 자동 지표 / 수동 오류 검토
정답의 출처 / 미확인 조건 / 실측과 추정의 구분
```

공개 저장소에는 평가 방법·재현 도구·직접 만든 예제를 둔다. 개인 녹음, 실제 강의 전사문, 계정 정보, 다운로드한 모델은 포함하지 않는다. 기존 기록의 알 수 없는 설정은 현재 설정으로 채우지 않고 미확인으로 남긴다.
