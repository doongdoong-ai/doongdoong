# 무료 계정 지원과 강의 처리량

2026-10-21 확인. **앱의 녹음·보관·재생은 무료이며 계정이 필요 없다. AI 전사부터 요약까지 무료 계정으로 몇 시간 사용할 수 있는지는 아직 산정할 수 없다.** 무료 계정의 해당 실행 경로 지원 여부와 사용량 한도라는 두 입력값이 확인되지 않았기 때문이다. ‘사용 불가가 확정됐다’거나 ‘무료 제공량이 0시간이다’라는 뜻은 아니다.

## 공개 문서로 확인한 범위

- GPT-6.1 Sol의 출시 지원 플랜에는 Plus·Pro 등이 포함되며 Free·Go는 포함되지 않는다. [공식 모델 안내](https://learn.chatgpt.com/docs/models#gpt-61-sol)
- 무료 계정에는 GPT-6 Luna의 데스크톱 앱 지원이 안내되어 있으며 점진 배포 조건이 있다. 이것만으로 CLI·`codex exec`·앱의 내부 ASR 경로 지원을 확정하지 않는다. [공식 가격·지원 안내](https://learn.chatgpt.com/docs/pricing)
- 공개된 Luna의 5시간당 350~3,000회 추정치는 **Plus·Standard Business** 기준이다. Free에 적용하거나 임의의 비율로 줄여 계산하지 않는다. 같은 요청 수라도 모델·문맥·추론·캐시 등에 따라 사용량이 달라진다. [공식 사용량 설명](https://learn.chatgpt.com/docs/pricing#what-are-the-usage-limits-for-my-plan)
- 내부 `POST /backend-api/transcribe`의 무료 계정별 음성 분량, 한도 초기화 주기, 별도 과금 규칙은 확인한 공개 문서에서 찾지 못했다. 공개 음성 API 요금이나 데스크톱 실시간 Voice의 분당 요금을 이 경로에 대입하지 않는다.

## 지금 계산할 수 있는 것은 강의당 처리량

파일은 최대 300초이며 끝의 10초 안에서 쉼을 찾아 자른다. 마지막 구간을 제외하면 290~300초이므로 다음 표는 **캐시·무음 생략·재시도·누락 구간 재처리를 제외한 기본 업로드 수**다. 녹음 중에도 파일을 닫은 뒤 보내며 실제 재생 시간만큼 기다리며 전송하는 구조가 아니다.

| 강의 길이 | 기본 파일 전사 요청 | 교정 묶음 추정 |
|---|---:|---:|
| 30분 | 6~7회 | 약 8개 |
| 60분 | 12~13회 | 약 16개 |
| 90분 | 18~19회 | 약 23개 |
| 120분 | 24~25회 | 약 31개 |

전사 요청 수의 하한은 `ceil(길이(초) / 300)`, 상한은 `1 + max(0, ceil((길이(초) - 300) / 290))`다. 양의 길이를 전제로 한다.

교정 추정은 기존 73분 5초 강의의 896문장을 길이에 비례해 환산하고 최대 48문장씩 나누었다. 해당 강의에서는 실제로 19개 교정 묶음을 완료했다. 이는 한 강의의 발화량을 이용한 거친 추정이며, 긴 문장은 바이트 제한에 먼저 걸려 묶음이 더 늘어날 수 있다. 제목·요약, 긴 문맥의 근거 추출, 교정 재시도는 별도다.

현재 녹음 중 전사에서는 구간마다 모델이 전사 도구를 호출한다. 녹음 완료 후 가져온 파일은 한 모델 턴 안에서 여러 ASR 파일을 처리할 수 있다. 따라서 **파일 업로드 수·모델 턴 수·사용량 차감량은 같은 단위가 아니다.** 모델이 음성을 직접 인식하지 않으므로 Luna로 전환해도 ASR 서버의 한도가 늘어난다고 볼 수 없다.

## 무료 이용 시간으로 환산하는 데 부족한 값

같은 초기화 주기에서 무료 계정의 ASR 제공량을 `A분`, 그 계정의 Codex 가용량을 `Q`, 강의 1시간 처리에 드는 실제 차감량을 `C`라고 하면 두 한도가 독립적일 때 가능한 강의 시간은 대략 `min(A / 60, Q / C)`다. 한도를 공유한다면 합산 사용량으로 다시 계산해야 한다. 현재는 `A`, `Q`, Free 계정에서의 `C`, 한도 공유 여부가 확인되지 않아 이 식의 결과를 숫자로 쓸 수 없다. Pro 계정으로 성공한 기록도 Free의 제공량을 증명하지 않는다.

무료 계정에서 별도 작업을 하지 않는 조건으로 CLI의 모델 목록·실제 요청 가능 여부를 확인하고, 30~60분 강의를 처리하며 전후 한도와 초기화 시각을 비교하면 해당 계정에 한정한 첫 추정치를 만들 수 있다. 이 길이는 **측정용 입력 크기**이며 무료 제공량의 예상치가 아니다. ASR이 사용량 계측을 제공하지 않는다면 성공한 누적 분량만 확인된 하한으로 기록한다. 한 번의 성공만으로 하루·주간 제공량을 발표하지 않는다.

## 앱의 모델 선택

일반 실행마다 `account/read`로 ChatGPT 로그인을 확인하고 `model/list`의 모든 페이지를 읽는다. 텍스트와 `medium`을 지원하는 표시 대상 중 `gpt-6.1-sol`을 우선하고, 없으면 `gpt-6-luna`를 선택한다. 모델 목록 조회에는 모델 턴이나 음성 업로드가 없다. [모델 목록 프로토콜](https://learn.chatgpt.com/docs/app-server#models)

목록에서의 지원과 실제 요청의 성공·남은 사용량은 별개다. 로그인·통신·목록 오류 때 Luna를 임의로 선택하지 않는다. 처리 도중 한도 초과나 서버 오류가 나면 기존 녹음·완료한 구간을 보존한다. 자동 API 키 결제로 전환하지 않는다. 교정 캐시는 선택한 모델별로 구분하며 이전 세션의 모델 선택을 저장해 재사용하지 않는다.
