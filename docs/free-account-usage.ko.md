# 계정 한도와 처리량

**녹음·보관·재생은 계정 없이 사용할 수 있지만, 무료 계정의 AI 처리 시간을 숫자로 보장할 근거는 없습니다.** 현재 음성은 ChatGPT 내부 받아쓰기 서버에 전송하고, 전체 교정·요약은 Codex 텍스트 모델을 사용합니다.

## 요청 수와 이용 한도는 다른 값

5분 파일 분할에서는 30분 강의가 보통 6~7개, 60분은 12~13개, 90분은 18~19개 파일 요청이 됩니다. 마지막 5초에서 쉼을 찾아 자르므로 정확한 수는 경계에 따라 달라집니다. 이 수에는 재시도·무음 생략·완료 캐시가 반영되지 않았습니다.

전사 과정은 Codex의 모델 턴을 시작하지 않습니다. Codex CLI에서 로그인 토큰을 받아 파일 서버에 요청합니다. 녹음이 끝나면 전체 전사문 교정은 기본 한 요청으로 처리하고, 용량을 넘는 경우에만 분할합니다. 제목·요약은 별도 요청입니다.

**파일 업로드 수, 텍스트 모델 요청 수, 계정 사용량 차감은 같은 단위가 아닙니다.** 내부 받아쓰기의 음성 제공량·초기화 주기·Codex 한도와의 관계·과금 규칙이 확인되지 않았으므로 공개 음성 API 요금이나 Pro 계정의 성공 사례를 Free 계정에 대입하지 않습니다. 앱에 API 키 결제나 유료 폴백은 구현되어 있지 않습니다.

## 모델 조회와 실제 권한

앱 실행 시 `account/read`와 `model/list`로 로그인과 모델 목록을 확인합니다. 자동 선택은 요청한 추론 강도를 지원하는 GPT-6.1 Sol을 우선하고 GPT-6 Luna를 다음으로 확인합니다. 모델 목록에 존재하는 것과 실제 요청 권한·잔여 할당량이 남아 있는 것은 다릅니다. 모델을 바꿔도 받아쓰기 서버의 모델이나 한도가 바뀐다고 볼 수 없습니다.

무료 계정에서 처리 시간을 추정하려면 다른 작업 없이 음성 전사와 교정·요약을 각각 실행하며 전후 이용 한도·초기화 시각을 기록해야 합니다. 한도가 노출되지 않는 단계는 성공한 누적 분량만 확인된 하한으로 남깁니다. 현재 공개할 수 있는 Free 계정 실측은 없습니다.
