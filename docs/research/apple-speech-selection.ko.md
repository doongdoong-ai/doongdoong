# Apple Speech 선택 근거: 한국어 정확도·처리 속도·모델 관리

**둥둥이는 한국어 강의를 처리하는 속도와 시스템 모델 관리의 이점을 고려해 Apple Speech를 기본 전사 엔진으로 선택했다.** 공개 벤치마크는 한국어에서 사용할 만한 후보라는 근거를 보태고, 자체 M1 측정은 기존 Whisper 구현보다 빠르게 동작한다는 근거를 제공한다. 정확도 우위가 입증된 선택은 아니다.

기록일: 2026-10-22. 아래에는 외부 작성자의 측정, 둥둥이의 측정, Apple이 설명한 API 동작을 구분해 보존한다. 새로운 벤치마크를 실행한 문서는 아니다.

## Whisper Notes의 한국어 비교

출처는 Whisper Notes Team의 [Apple SpeechAnalyzer vs Whisper: Apple의 새 온디바이스 음성 인식은 얼마나 정확할까?](https://whispernotes.app/ko/blog/apple-speech-vs-whisper)다. 게시일은 **2026-09-01**, 원문 확인일은 **2026-10-22**다. 전사 앱 개발사가 직접 수행한 비교이며, 둥둥이가 원시 출력과 채점 코드를 재실행해 검증한 결과는 아니다.

원문에 기재된 조건은 **M5 MacBook Air·32GB·macOS 27.0**, Google FLEURS test 리비전 `70bb2e84`, 언어당 약 150문장·30분이다. 같은 클립을 같은 순서로 엔진별로 순차 처리했다. 한국어는 문자 오류율(CER)을 사용한다. CER은 정답 글자 수에 대한 치환·삭제·삽입 오류의 비율이며 낮을수록 좋다.

| 엔진 | 한국어 CER |
|---|---:|
| Qwen3-ASR 1.7B | 3.54% |
| Whisper Large V3 Turbo | 4.25% |
| **Apple SpeechTranscriber** | **4.31%** |
| Apple Dictation | 7.11% |
| Whisper Small | 7.30% |
| SenseVoice Small | 7.85% |

수치는 해당 글의 한국어 행에서 가져왔다. Apple Dictation은 이전 받아쓰기 모델을 사용하는 비교 대상이며, 둥둥이가 채택한 `SpeechTranscriber`와 구분한다. 이 글의 Parakeet V3 비교에는 한국어 결과가 없다.

Apple과 Whisper Large V3 Turbo의 차이는 **0.06%p**, Apple과 Qwen3-ASR 1.7B의 차이는 **0.77%p**다. 점수가 가깝다는 관찰은 가능하지만 통계적 동등성이나 실제 강의에서의 동률을 확정하지 않는다. 원문의 ‘약 1점 미만이면 동률’이라는 서술도 일반적인 통계 기준으로 채택하지 않는다. FLEURS의 짧고 깨끗한 낭독 음성은 강의실의 거리·잡음·전문용어·긴 녹음 조건과 다르다.

원문은 여러 언어의 처리량 중앙값으로 Apple **실시간의 30.8배**, Qwen3-ASR **11.1배**, Whisper Large V3 Turbo **3.0배**를 보고한다. 엔진마다 지원·측정 언어가 다르므로 이를 한국어 강의의 속도나 둥둥이의 소요 시간으로 사용하지 않는다. Apple의 최대 메모리는 보고하지 않았으며, 표의 `<5 MB`를 언어 모델까지 포함한 전체 디스크 사용량으로 인용하지 않는다.

## 둥둥이의 M1 비교와 차이

자체 비교 환경은 **MacBook Air M1·8GB·macOS 26.3**이다. 금융 강의의 앞 5분·중간 5분·마지막 5분, 총 15분을 동일한 18개 PCM 구간으로 나눠 두 엔진에 전달했다. 비교 대상은 당시 제품의 **Whisper large-v3-turbo FP16 + Silero VAD**, whisper.cpp 1.9.5, 한국어, threads 4, beam/best-of 5 설정이다. 원문과 최종 판단은 [이슈 #12](https://github.com/doongdoong-ai/doongdoong/issues/12)에 기록했다.

| 같은 금융 강의 15분 | 처리 시간 |
|---|---:|
| Apple Speech | **9.37초** |
| 기존 Whisper 구현 | **115.64초** |

각 구간의 PCM 해시와 분할 경계가 일치하는 조건에서 **약 12.3배**의 처리 속도 차이를 확인했다. 조건별 1회 실행이며 최초 초기화는 포함하지만 OS 캐시를 강제로 비우지 않았다. 교정·요약은 제외했다. 녹음 중 이미 전사하는 앱이므로 이 배율을 녹음 종료 후 전체 대기 시간에 그대로 적용하지 않는다.

자체 FLEURS 한국어 **24개·5분 20.7초·정답 1,236자** 표본에서는 Apple CER **7.28%**, Whisper **6.15%**로 Whisper의 오류가 더 적었다. 공백·문장부호 제외, NFC·소문자 정규화 후 계산했다. Apple−Whisper 차이 +1.13%p의 발화 단위 bootstrap 95% 구간은 **−0.48~+2.87%p**다. 작은 표본으로 일반적인 우열이나 동등성을 확정할 수 없다.

외부 결과와 자체 결과는 표본·OS·하드웨어·실행 구현·정규화 조건이 다르다. 점수를 합치거나 유리한 쪽으로 대체하지 않는다. 실제 금융 강의에서도 양쪽 모두 전문용어·숫자·시험 안내를 잘못 인식한 사례가 있었다. 이 강의에는 사람이 검수한 정답이 없어 클로바노트 출력을 정답으로 채점하지 않았다.

전환 후 **73분 5.4초 전체 파일의 처리 완주·캐시 재사용·시간 정보 검증**도 수행했다. 이는 정확도 재평가와 구분하며, 상세 범위는 [전환 검증 기록](../validation-apple-transcription.ko.md)에 남겼다. 원음·전체 전사·실행 로그는 비공개 `.local/apple-whisper-benchmark-2026-10-22/`와 `.local/apple-migration-2026-10-22/`에 보존한다.

## Apple API와 설치 부담

Apple의 [WWDC25 SpeechAnalyzer 세션](https://developer.apple.com/videos/play/wwdc2025/277/)은 `SpeechTranscriber`를 긴 음성·대화·먼 거리 화자·낮은 지연 시간을 고려한 온디바이스 모델로 설명한다. `AssetInventory`로 필요한 모델을 설치하며, 시스템이 저장과 업데이트를 담당한다. 추론은 앱의 메모리 공간 밖에서 수행한다. 이는 **Mac 전체의 메모리·디스크 사용량이 0이라는 뜻이 아니다.**

둥둥이의 전사 코어 `0.3.0`은 `SpeechAnalyzer`와 `SpeechTranscriber`를 사용한다. 별도 Whisper 실행 엔진·모델 설치 경로·Silero 의존성을 제거했고, 언어 지원·설치 여부는 실행 시 확인한다. 최소 지원 범위는 **macOS 26 이상의 Apple Silicon Mac**이다. 언어 모델을 처음 준비할 때는 다운로드가 필요하다.

`DictationTranscriber`는 Apple이 제공하는 별도 호환성 모듈이다. 현재 둥둥이는 이를 자동 대체 엔진으로 연결하지 않는다. 지원되지 않는 언어·기기에서는 설정에 안내한다. API의 가변 결과는 선택 사항이며, 둥둥이는 확정 결과만 사용하고 전체 교정이 검증된 뒤 전사문을 공개한다.

음성 인식은 로컬에서 수행하지만, 이어지는 교정·제목·핵심 요약은 연결한 Codex에 **텍스트를 전달**한다. 전사 엔진의 온디바이스 특성을 앱 전체의 오프라인 동작으로 확대하지 않는다.

## 제품 선택과 재평가 기준

기본 엔진은 Apple Speech로 유지한다. 한국어의 공개 점수, M1에서 직접 확인한 처리 속도, 모델 관리 부담을 함께 고려한 결정이다. Qwen3-ASR의 한국어 점수는 후속 비교 후보를 보여 주지만, 이 문서에서 해당 모델을 M1로 실행하거나 장시간 강의 성능을 검증한 것은 아니다.

향후에는 사람이 검수한 한국어 강의의 전문용어·숫자·부정 표현·시험 안내를 기준으로 인식 원문과 교정 이후 결과를 각각 비교한다. Apple 모델은 시스템 업데이트로 달라질 수 있으므로 OS·언어·입력 해시·분할 조건을 함께 남긴다. 현재 측정만으로 다른 언어의 정확도나 모든 Mac의 처리 시간을 보장하지 않는다.
