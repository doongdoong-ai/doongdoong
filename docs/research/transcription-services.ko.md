# 녹음·전사 서비스 비교

확인일: 2026-10-18. 제품 공식 페이지의 현재 기능·요금·한도를 조사했다. 한국 대학생의 이용 순위나 시장점유율 조사는 아니다. 소개 문구는 “이미 구독 중인 AI와 Mac으로, 별도 전사 서비스 구독을 줄인다”를 중심으로 구성했다.

## 직접 비교하는 서비스

| 서비스 | 공식 안내에서 확인한 조건 | 둥둥이 소개에 반영한 점 |
|---|---|---|
| [클로바노트](https://help.naver.com/service/24269/contents/12814?lang=ko) | 월 기본 300분, 데이터 수집 동의 시 300분 추가, 1회 180분. 개인용 시간 구매 미지원 | 무료 제공량의 제약과 유료 서비스 구독을 구분 |
| [다글로](https://daglo.ai/d/ko/pricing) | Free는 녹음 월 4시간, 파일·YouTube 월 4시간, 월 1,000 크레딧. Pro는 녹음 무제한, 파일·YouTube 월 45시간. 연 결제 142,800원 | 녹음 시간과 요약용 크레딧은 다른 제한. 유료도 모두 시간제라고 표현하지 않음 |
| [Notta](https://www.notta.ai/ko/pricing) | Free 월 120분, 대화당 최대 3분, 요약 월 10회. Pro 월 1,800분, 연 결제 $97.99 | 월 총량만 아니라 긴 수업 한 건을 처리할 수 있는지 함께 비교 |
| [Tiro](https://tiro.ooo/ko) | 3주 체험, 기본 100분에 시작 과제 완료 시 최대 300분. 노트당 50분. Lite 월 300분, Pro 월 1,000분, Max 무제한 | 매월 무료 제공과 기간 한정 체험 구분. 가격 숫자는 페이지 추출에서 확인되지 않아 기재하지 않음 |
| [PLAUD](https://global.plaud.ai/pages/plaud-ai-plan-pricing) | 기기에 Starter 월 300분 포함. Pro 월 1,200분, Unlimited는 일 24시간 상한. 국가별 가격 차이 | 하드웨어 비용과 AI 구독을 분리. “기기만 사면 AI가 무제한”이라고 오해하지 않도록 설명 |

네이버 고객센터는 웹 검색 도구에서 본문이 누락되어, 동일 공개 페이지의 HTML과 `__NEXT_DATA__`에 있는 본문·요약을 직접 확인했다. 클로바노트 개인용과 [네이버웍스 비즈니스용](https://naver.worksmobile.com/pricing/clovanote/)은 별도 상품이다. 비즈니스 Lite의 월 비용은 기업 단위이며 개인용 가격이나 인당 가격으로 사용하지 않았다.

표는 상품의 일부 조건을 요약한 것이다. 음성 인식 정확도, 체감 속도, 장애율을 직접 비교 측정하지 않았다. 다른 서비스의 화자 분리·번역·공유 기능까지 둥둥이가 대체한다고 주장하지 않는다.

## 학습 경험을 참고할 인접 제품

- [Turbo AI](https://www.turbo.ai/): 구 TurboLearn. 강의 녹음·자료에서 노트와 학습 도구를 만드는 제품. 공식 사이트가 학생 사용 후기를 제시하지만 이를 독립적인 이용률 통계로 사용하지 않는다.
- [Gemini Notebook / 구 NotebookLM 공식 안내](https://support.google.com/gemininotebook/answer/16213268?hl=ko): 자료를 기반으로 공부하는 인접 제품. Google AI 구독에 따라 이용 범위가 달라지므로 “모든 학습 앱은 별도 구독이 필요하다”는 주장은 피한다. 녹음 앱과 같은 분 단위 기준으로 단순 비교하지 않는다.

## 둥둥이의 비용·처리 경계

로컬 Whisper 전사는 외부 서비스의 월별 전사 시간 할당량을 사용하지 않는다. Mac의 연산 시간·메모리·디스크를 사용한다. Codex 교정과 요약은 기존 ChatGPT 계정의 Codex 사용량을 소비한다. 텍스트 처리는 OpenAI 서버에서 수행되므로 전체 로컬 AI나 무제한 무료라고 소개하지 않는다. [OpenAI 공식 요금·사용량](https://learn.chatgpt.com/docs/pricing)

현재 구현은 Codex CLI만 연결한다. Claude 구독을 활용하겠다는 확장 취지와 현재 지원 기능은 구분하며, README에 Claude 지원을 약속하지 않는다.
