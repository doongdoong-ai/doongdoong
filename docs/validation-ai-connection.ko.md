# AI 연결 확인과 최초 설정

2026-10-27 · codex-core 0.3.0

이 문서는 당시 검증 기록입니다. 2026-10-28부터 녹음 시작을 자동 정리 흐름으로 통합했으며, 아래의 `녹음만 이용하기`는 제거했습니다. 현재 동작은 [기술 안내](technical-guide.ko.md)를 참고하세요.

연결 성공 기준을 계정·모델 목록 조회에서 **선택한 모델의 실제 JSON 응답 검증**으로 바꿨습니다. 첫 확인에 실패하면 복구 화면을 띄우며, 원인 불명 오류를 포함해 녹음만 먼저 이용할 수 있습니다. 그 선택은 AI 설정 완료로 저장하지 않습니다.

## 확인한 동작

| 범위 | 검증 |
|---|---|
| 벤더 코어 | 설치·인증 방식·모델 선택, 잘못된 JSON, 시간 초과, 취소, 미분류 오류, 사용 한도 재설정 시간 |
| 로그인 | 공식 HTTPS 주소만 열기, 로그인 ID 일치 확인, 실패·프로세스 종료·시간 초과·취소 |
| 앱 상태 | 최초 실패와 재시도, 녹음만 이용하기, 성공 후 강의 시작 이어가기, 설정 완료와 현재 연결 상태 분리 |
| 데이터 보존 | 연결 전에는 저장된 녹음을 처리하지 않음, 여러 대기 파일을 저장 상태로 유지, 기존 공개 전사문 보존 |
| 경합 | 취소한 확인의 늦은 응답 무시, 새 모델 설정에는 재확인 필요, 안내창과 녹음 폴더 선택창 순서 보장 |
| 화면 | 원인 불명·로그인·설치·사용 한도 안내와 설정 3개 상태, 총 7개 오프스크린 렌더 |

코어 테스트 25개와 앱 테스트 141개, 두 저장소의 release 빌드를 검증했습니다. 자동 테스트는 가짜 CLI와 격리된 환경을 사용하며 계정 로그인이나 실제 음성 인식을 실행하지 않습니다. 화면 검증에서도 사용자 라이브러리를 열거나 앱 포커스를 가져오지 않았습니다.

실제 설치된 Codex로 GPT-6.1 Sol / medium의 연결 확인을 한 번 실행해 약 8.43초에 성공했습니다. 테스트 요청에는 고정된 빈 JSON만 넣었으며 녹음·전사문은 사용하지 않았습니다. 브라우저 로그인은 가짜 CLI로 검증했으며, 실제 사용자 계정을 로그아웃하거나 재로그인하지 않았습니다.

## 경계

- 실제 확인 요청에도 계정 사용량이 적용됩니다. 연결 성공이 이후 요청의 잔여 사용량을 보장하지는 않습니다.
- 전체 확인 제한은 90초, 브라우저 로그인 제한은 180초입니다. 자동 재시도하지 않습니다.
- 구조화된 근거가 없는 실패는 `unknown`으로 남깁니다. 원문 오류를 추측해 재로그인이나 결제를 안내하지 않습니다.
- 진단 복사는 공급자·단계·분류·재시도 정보만 포함합니다. 인증 정보와 원문 오류는 포함하지 않습니다.
- 실제 로그인 화면이나 브라우저 콜백은 CLI 버전·브라우저 환경에 따라 달라질 수 있습니다.
