# Apple Speech 전사 전환 검증

2026-10-22 · MacBook Air M1·8GB · macOS 26.3.

## 전환 이유와 범위

이전 비교에서 동일한 금융 강의 15분을 같은 18개 PCM 구간으로 처리했을 때 Apple은 9.37초, 현재 Whisper는 115.64초였다. FLEURS 한국어 24개 문자 오류율은 Apple 7.28%, Whisper 6.15%로, 작은 표본에서 Apple의 정확도 우위가 입증된 것은 아니다. 제품 결정은 빠른 처리와 시스템 모델 관리의 이점을 선택한 것이다. 원 비교는 GitHub 이슈 #12에 보존한다.

전사 코어 0.3.0은 Apple `SpeechAnalyzer`와 `SpeechTranscriber`를 사용한다. Whisper 실행·설치 경로와 모델 설정을 제거했다. Codex 보정·요약은 별도 모듈과 기존 프롬프트를 유지한다. 최소 OS는 macOS 26이다.

## 기능 검증 결과

| 확인한 항목 | 결과 |
|---|---|
| 코어 테스트 | 18개 통과. 실제 설치된 한국어 모델의 전사·실행 중 취소·재요청 포함. |
| 앱 테스트 | 106개 통과. 중단 복구, 교정 전 비공개, 새 언어 설정과 타임스탬프 호환 포함. |
| 금융 전체 파일 | 73분 5.415초, 75개 구간 완료, 697개 읽기 구간. 마지막 PCM 프레임까지 체크포인트 저장. |
| 전체 파일 실행 시간 | 46.86초. Codex 호출 제외, 1회 기능 검증이며 일부 앱 빌드와 겹쳤으므로 독립적인 속도 벤치마크로 사용하지 않는다. |
| 같은 작업 재실행 | 0.22초, 전사 결과 파일 동일. 완료된 구간을 재사용. |
| 시간 정보 | 유한값·음성 범위·시간 순서 검사 통과. 실제 발화와의 정밀 정렬은 사람 청취로 검수하지 않음. |
| UI | 설정·전사문·처리 화면의 창 없는 렌더링 통과. 사용자 화면 전환 없음. |
| 빌드 | 코어 release 빌드, 앱 패키징 및 ad-hoc 서명 검증. |

정확도 재평가나 Apple→Codex 최종 보정 품질 비교는 이 기능 검증에 포함하지 않는다. 73분을 파일로 처리한 결과를 실제 73분 마이크 녹음·배터리·잠자기 하드웨어 실험으로 간주하지 않는다. 실제 모델 다운로드 실패와 OS 업데이트 후 모델 변경은 별도 환경에서 추가 검증이 필요하다.

## 중단·호환과 설치

구간 분석은 180초 제한을 두며 취소 시 Apple 분석을 종료한다. 성공적으로 저장된 구간만 재사용하고, 다운로드 준비 실패는 음성 커서를 전진시키지 않는다. 완료된 체크포인트는 모델이 준비되지 않았어도 읽을 수 있다. 기존 녹음과 사용자 편집은 보존하며 `whisper`·`aligned` 시간 표시도 계속 읽는다. Apple 체크포인트와 이전 엔진의 체크포인트는 섞지 않는다.

한국어 모델이 `installedLocales`에는 있지만 `AssetInventory.status(forModules:)`에는 `supported`로 보고되는 경우를 실제 확인했다. 설치 목록을 우선 확인해 불필요한 재다운로드 안내를 막는다. 앱 설정에서 지원 상태와 언어 모델 준비·다운로드 진행을 확인한다.

기존 `auto` 언어 설정은 한국어로 이관한다. Apple 모델 자산은 시스템이 관리하며 다른 앱과 공유될 수 있으므로 삭제하지 않는다. 과거 앱 전용 모델 파일과 연구 결과도 자동 삭제하지 않는다. 현재 전사 경로에서 이 파일들을 로드하지 않는다.

재현 자료와 전체 전사문은 비공개 `.local/apple-migration-2026-10-22/`, 코어 테스트 로그는 전사 코어 `.local/`에 보관한다. 이전 구현 복구 기준은 전사 코어 `docs/restore-whisper.ko.md`에 남겼다.
