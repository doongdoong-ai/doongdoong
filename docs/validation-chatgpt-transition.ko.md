# ChatGPT 파일 전사 전환 검증

**한국어 강의에서 관찰한 전사 속도·전문용어 인식을 근거로 ChatGPT 파일 받아쓰기를 선택했습니다.** 정확도 전반의 우위를 증명한 선택은 아닙니다. 이번 구현 검증과 이전 성능 측정을 구분합니다.

## 선택에 사용한 기존 비교

M1 MacBook Air·8 GB에서 같은 금융 강의의 앞 19분 56초를 동일한 5분 구간 4개로 나눴습니다. ChatGPT 받아쓰기 30.94초, Whisper large-v3 Q5_0 483.63초였습니다. 후반 설명에서 받아쓰기는 `금본위제·태환·세계화폐`, large-v3 Q5는 `금고리제·퇴완·세계화표`로 출력했습니다. 강의 전체를 사람이 청취해 만든 정답지는 없으므로 이 사례를 정확도 백분율로 바꾸지 않습니다.

Whisper 시간은 모델 로딩 4회가 포함되고, 받아쓰기 시간에는 사전 AAC 변환과 최초 app-server 시작이 빠져 있습니다. 둘 다 정렬·교정·요약을 제외한 전사 측정입니다. 이전 전체 73분 받아쓰기 실측 115.502초 역시 앱 전체 완료 시간이 아닙니다. 현재 상주 Turbo·VAD·60초 분할과 같은 교정을 붙인 통제 비교는 수행하지 않았습니다.

깨끗한 한국어 FLEURS 24개·정답 1,236자에서는 Turbo CER 6.07%, 받아쓰기 6.88%였습니다. 차이의 95% 구간은 0을 포함합니다. 금융 강의의 마지막 시험 범위 안내는 받아쓰기에서도 누락됐습니다. 비교 출력인 클로바노트를 사람이 만든 정답지로 취급하지 않습니다.

## 인식 품질 검사와 통합 검사는 구분

첫 앱 통합 실행은 처리 자체가 약 38.43초에 완료됐지만 마지막 참조 구절 `읽을 수 있도록`이 다른 표현으로 인식되어 기존 문구 검사를 통과하지 못했습니다. 이 실패를 보존했습니다. 이후 검사에서는 기능 무결성과 참조 구절 일치 여부를 별도 필드로 기록하도록 분리했습니다. 새로 실행한 통합에서는 시작·끝 참조 구절 둘 다 일치했습니다. **후속 성공이 첫 오인식을 없애지는 않으며, 짧은 합성 음성에서도 출력 변동이 있음을 보여줍니다.**

이번 30.34초는 단일 샘플의 앱 처리 시간이며 속도 보장이 아닙니다. 실제 강의의 5분 이상 마이크 녹음, 새로운 경로로 73분 전체 처리, 전체 문장 청취 평가, 실제 덮개 잠자기·배터리 방전은 이번에 재실행하지 않았습니다. 합성 PCM과 가짜 공급자의 복구 테스트는 물리적인 전원 차단 검증과 다릅니다.

내부 받아쓰기 경로의 계정별 한도·과금·지속 제공은 확인되지 않았습니다. 상세 구조는 [기술 문서](technical-guide.ko.md), 이전 로컬 전사 복원은 [복원 지침](restore-whisper.ko.md)을 참고하세요. 개인 녹음·전사문·인증정보·실행 로그는 공개하지 않습니다.
