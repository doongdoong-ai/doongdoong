# 파일 전사·따라읽기 검증 기록

2026-10-21, Apple M1 · 메모리 8 GiB에서 검증했다. 이번 변경은 Whisper 기반 음성 인식을 5분 단위 파일 전사로 교체하고, 로컬 음향 정렬과 전체 강의 교정을 연결한다. [이전 버전 검증](validation.md)은 Whisper 경로의 기록이며 현재 엔진의 결과로 해석하지 않는다.

**73분 녹음의 전체 처리와 저장·재생은 확인했지만, 중요한 발언을 정확히 보존하는지에 대한 품질 검증은 아직 부족하다.** 개인용 베타 수준으로 판단하며 서비스 간 정확도 우위를 주장하지 않는다.

## 자동 검사

| 검사 | 범위 | 결과 |
|---|---|---|
| Swift 단위 테스트 | 분할·캐시·중단 복구, 인증 분기, 교정 검증, 저장·재생 모델 등 | 서로 다른 테스트 75개 통과 |
| Python 정렬 테스트 | 시간축, 정렬 불확실성, 원문 보존 등 | 7개 통과 |
| 오프스크린 UI | 기본·최소 크기·설정·검색·처리 중·음성 확인 등 | 12개 화면 통과 |

화면 검사는 창을 표시하지 않고 같은 SwiftUI 뷰를 렌더링한다. 최소 창 크기의 음성 확인 배너도 직접 검토했다. 사용자 포커스를 옮기는 실제 창 조작이나 마이크 장치 검사는 포함하지 않는다.

## 실제 서버를 사용한 처리 검사

실제 강의 파일 하나를 별도 라이브러리에 가져와 15개 구간 전사, 시간 정렬, 누락 의심 구간 재처리, 전체 교정, 제목·핵심 요약 저장까지 실행했다. 19개 교정 묶음을 완료했고 문장 ID·순서·교정 전 원문·시간이 보존되는지 확인했다.

같은 앱 통합 검사에서 잘못된 파일 거부, 재생 시계·속도·탐색·끝부분 반복, 북마크, 저장 실패 후 편집 보존, 폴더 이동·재실행 로드, SRT 내보내기를 확인했다. 27초 합성 한국어 음성으로도 전체 경로를 실행했다. 합성 음성의 성공은 실제 강의의 인식 정확도를 대표하지 않는다.

녹음 중 전송은 실제 음성 PCM을 점차 늘어나는 WAV에 기록하는 방식으로 모사했다. 실제 Sol·받아쓰기 요청으로 첫 구간 응답을 저장하고, 종료 후 최종 처리에서 같은 응답을 재사용하며 원본 바이트가 유지되는지 확인했다. 실제 마이크로 5분 이상 녹음한 실험과는 구분한다.

## 품질과 측정의 한계

- 전문용어와 마지막 시험 범위 안내에 의미가 달라지는 오인식이 남았다. 모든 파일 구간을 전송한 것과 모든 발언을 정확히 인식한 것은 다르다.
- 정렬이 불확실한 문장과 누락 의심 구간이 남았다. 표시와 재생은 확인했지만 모든 문장의 시간을 사람이 청취해 채점하지는 않았다.
- 클로바노트 출력과의 문자 차이는 비교했으나, 사람이 원음을 듣고 작성한 정답지가 아니다. 이를 정확도·CER·WER나 제품 간 우위로 발표하지 않는다.
- 음향 확률이나 기존 응답을 재사용한 실행이 포함된다. 실행 계측 시간과 산출물의 시작·종료 시각에도 원인 미확정 차이가 있어 실제 대기 시간이나 처리 속도를 보장하지 않는다.
- 실제 절전·마이크 분리·장시간 오프라인 복귀, Intel Mac, 다양한 강의·언어·녹음 환경은 추가 검증이 필요하다.
- 내부 받아쓰기 경로의 과금 규칙과 장기적인 제공 여부는 검증하지 못했다. 관련 범위는 [기술 문서](technical-guide.ko.md#실행-위치와-인증과금)에 설명한다.

원본 녹음, 전사문, 계정정보와 개인 비교 자료는 공개하지 않는다. 로컬 검증 산출물은 Git에서 제외된 `.local/`에 보관한다.

## 다시 실행하기

모델 요청 없이 실행하는 검사는 다음과 같다.

```sh
swift test
python3 -m unittest discover -s Tests/Alignment
./scripts/build-app.sh
python3 scripts/verify-ui.py --skip-build
```

`./scripts/verify-integration.sh`는 별도의 합성 샘플 라이브러리에서 **실제 음성 전사와 Codex 요청**을 보낸다. 일반 단위 테스트와 다르게 계정 사용량이 발생하므로 실제 서버 경로를 검증하려는 경우에만 실행한다. 이번 PR 준비 중에는 기존 서버 검증 결과를 사용하고 새 전사 요청을 보내지 않았다.
