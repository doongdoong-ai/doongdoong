# 설정·핵심 요약 화면 개편

2026-10-23. 저장 폴더를 여는 기능을 제거하고, 설정과 핵심 요약의 정보 위계를 정리했다. 전사·교정·요약 모델과 저장 형식은 변경하지 않았다.

## 변경 범위

- 저장 폴더 열기: 사이드바, 파일 메뉴, 설정의 경로 영역, 폴더·녹음의 Finder 메뉴와 실행 함수를 제거했다. 녹음 보관·내보내기는 유지한다.
- 설정: 음성 인식·AI 연결·단축키의 왼쪽 내비게이션, 상태와 조치를 함께 보여 주는 Codex 연결 카드, 항목별 이름·설명·우측 컨트롤을 적용했다. 기본 창은 820×700pt, 최소 크기는 760×600pt이며 본문을 스크롤할 수 있다.
- 고급 항목: 요청 제한 시간과 실행 파일 경로를 접어 두었다. 실행 경로는 편집 후 적용하며, 실행할 수 없는 파일이나 디렉터리는 저장하지 않는다. 음성 인식 문제의 설정 버튼은 음성 인식으로, 재개 시 AI 연결 문제는 AI 연결로 이동한다.
- 핵심 요약: 반복되는 안내 제목을 줄이고 카드 제목·본문을 먼저 배치했다. 하단에 원음 재생·강조 유형·근거 펼치기·복사를 모았다. 근거는 별도 인용 영역에 표시하고, 본문과 근거의 텍스트 선택을 유지했다. 한국어 어절을 우선해 줄바꿈한다.
- 새 녹음: 위아래 여백을 각각 6pt 늘렸다. 녹음 중·마무리 중에도 같은 크기를 사용한다.

## 검증

- 기존 Swift 테스트 111개 통과. 설정 보존·작업별 스냅샷·재개·교정 결과 검증을 포함한다.
- 릴리스 빌드와 ad-hoc 서명 검증 통과.
- 릴리스 앱의 설정·요약 화면 18개를 격리된 라이브러리로 렌더링했다. 표시된 창 0개, 앱 활성화 없음, 정상 종료를 확인했다.
- 음성 인식 준비 완료·다운로드 필요·지원되지 않는 언어, Codex 연결·로그인 필요·연결 실패·실행 파일 없음·자동 정리 꺼짐, 고급 설정·단축키·최소 창 크기를 확인했다.
- 요약 두 장·긴 제목과 본문·빈 결과·여러 근거를 펼친 화면을 확인했다. 긴 본문과 고급 항목은 스크롤 범위에 포함된다.

설정 화면은 격리된 설정 저장소와 가짜 연결/언어 상태를 사용한다. 요약 화면은 합성 강의 데이터를 사용한다. 실제 마이크·인식·Codex 요청은 실행하지 않았으며, 이 검증은 새 음성 인식 정확도나 실계정 연결 검증을 뜻하지 않는다. 원본 렌더링·로그·보고서는 비공개 `.local/settings-redesign-2026-10-23/`에 남겼다.

디자인 참고 자료와 적용 기준은 [디자인 레퍼런스](design-references.md)에 정리했다.
