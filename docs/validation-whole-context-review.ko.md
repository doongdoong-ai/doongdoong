2026-10-21, 같은 77분 14초 금융 강의의 Whisper 원문 857문장·21,534자를 GPT-6.1 Sol / medium으로 교정했다. v4는 원문 전체를 읽고 `{ids, before, after}` 수정 계획만 반환한다. 정상 JSON의 일부 편집이 검증에 실패해도 전체를 재생성하지 않는다.

v4의 실제 모델 실행은 1회·263.702초였다. 최종 검증기는 동일 응답을 오프라인에서 재적용했다(1.251초, 모델 추가 호출 없음). 기존 전체 방식은 2회 요청했으며 첫 호출은 약 210초였다. 새 방식의 이점은 정상 편집을 보존해 전체 재생성을 없앤 데 있고, 모델 호출 자체가 더 빨라졌다고 주장하지 않는다.

평가는 반복 전문용어 8종·23곳과 문장 ID·시각·숫자 보존, 새 문법 오류 확인으로 좁혔다. 표적은 기존 결과를 참고해 선택했으며 검증기도 같은 강의로 개선했다. 독립 평가나 오디오 정답에 대한 CER/WER이 아니다. 반복 표기 누락, 고유명사 불확실성, 일부 정상 제안을 막는 휴리스틱의 한계가 남는다.
