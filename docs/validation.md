# 이전 버전 검증 기록

당시 버전의 검증 기록이며 이후 추가된 기능의 검증 결과를 포함하지 않습니다. 과거 화면 캡처와 로컬 절대 경로는 공개본에서 제외했습니다.

2026-10-18, Apple M1 · 메모리 8 GiB · macOS 26.3 · Swift 6.2.1에서 검증했습니다. 실제 사용자 음성이나 개인 파일은 사용하지 않았습니다.

## 파일 일괄 처리와 AI 교정

[통합 검증 결과](integration-report.json)는 배포용 앱에 27.105625초의 합성 한국어 WAV를 가져와 **Whisper large-v3-turbo FP16 → 기존 ChatGPT 로그인으로 Codex 텍스트 교정 → 저장**을 실제 실행한 결과입니다. 약 17.56초에 처리됐으며 7개 구간의 ID·시작/종료 시간·원문 보존을 확인했습니다. 이 시간은 한 번의 샘플 실행이며 긴 녹음이나 다른 네트워크 조건의 속도를 보장하지 않습니다.

같은 검사에서 잘못된 파일 거부, 가져오기 임시 파일 정리, 재생 시계·1.5배속·문장 반복·파일 끝 반복, 탐색·북마크, 디스크 쓰기 실패 시 메모 보존·종료 보류·복구, 폴더 이동·재로딩, SRT 내보내기를 확인했습니다.

[모델 단독 실측](whisper-m1-turbo-benchmark.json)은 같은 27.1초 음성을 약 5.74초와 5.26초에 처리했습니다. 새 프로세스에서 모델 로딩을 포함하며 Codex 시간은 제외합니다. 두 번째 실행의 진단 로그에서 Apple M1의 Metal `MTL0` 사용을 확인했습니다. 모델 파일은 배포자가 제공한 SHA-256 값과 일치합니다.

이 검사는 정확도 벤치마크가 아닙니다. 샘플에서 ‘글이 됩니다’는 올바르게 인식했지만 ‘북마크’를 ‘붕마크’로 인식한 오류는 교정 후에도 남았습니다. 원문 보기·문장 편집을 제공하며, 시간정보는 모델이 추정한 발화 구간입니다.

## 실패·취소와 결과 보존

`swift test`의 26개 테스트가 통과했습니다. 저장소 이동·복구·읽기 전용 오류, UTF-8 경로 길이, 심볼릭 링크·잘못된 메타데이터, 시간 경계·비정상 값, 응답 ID 검증, 교정 요청 크기 분할·과도한 축약과 확장 거부, 프로세스 취소·타임아웃·하위 프로세스 종료·환경변수 필터를 포함합니다.

실제 파이프라인을 독립 컴파일하고 가짜 CLI로 검증한 6개 시나리오도 통과했습니다. 60문장/2개 묶음 성공, 두 번째 묶음 실패 시 전체 원문 복원, ChatGPT 외 인증 거부, 교정 중 취소와 원문 파일 보존, 전사 오류의 사용자용 안내, API 환경키 필터를 확인했습니다. 이 가짜 CLI 검사는 실제 서비스 호출 성공과 별도이며, 실제 호출은 위 통합 검사로 확인했습니다.

기존 로그인에 영향을 줄 수 있는 `forced_login_method` 설정은 사용하지 않습니다. 앱이 토큰 파일을 직접 읽지 않고 CLI의 로그인 상태를 확인합니다. 읽기 전용 sandbox, 개인 설정·규칙 제외, 지정 도구 비활성화와 전사문을 데이터로 취급하는 지시를 적용했습니다. 공개 CLI에 모든 도구를 일괄 제거하는 옵션은 없으므로 모든 관리형 MCP 설정까지 차단한다고 주장하지 않습니다.

## 화면과 백그라운드 실행

[오프스크린 검증 결과](offscreen-validation.json)는 기본·최소 크기·메모·집중·설정·첫 실행·전사문·검색·검색 결과 없음·처리 중·교정 중의 11개 화면 모두 통과했습니다. 각 검사에서 표시 창 0개, 비활성 상태, 활성화 정책 `.prohibited`, 활성화 이벤트·전면 포커스 획득 없음, 정상 종료, PNG 크기를 확인했습니다. 기존 사용자 라이브러리를 사용하지 않았습니다.

당시 진행 화면과 내부 교정 단계 화면은 모두 동일한 ‘AI가 녹음을 정리하고 있어요’ 안내를 표시했습니다. 설정에서는 언어·AI 연결·저장 위치를 보여 주며 엔진 경로는 접힌 고급 설정에 두었습니다. 화면을 직접 확인해 잘림과 중복을 점검했습니다.

검증은 네이티브 창을 앞으로 띄우는 대신 메모리에 같은 SwiftUI 뷰를 렌더링합니다. 따라서 실제 창 이동이나 하드웨어 입력 검사와는 구분됩니다.

## 설치와 재현

[설치 기록](turbo-installation.json)에 설치본·이전 버전 백업·실행 파일 SHA-256을 기록했습니다. 배포본과 설치본 해시가 일치하며 `codesign --verify --deep --strict`를 통과했습니다. WebRTC helper와 Python 런타임은 포함하지 않습니다. 실행 중인 앱은 강제로 종료하거나 재시작하지 않았습니다.

```sh
./scripts/setup-engine.sh
swift test
./scripts/build-app.sh
python3 scripts/verify-ui.py --skip-build
./scripts/verify-integration.sh
```

통합 검사는 임시 라이브러리와 합성 샘플을 사용하고 실제 Codex 교정 요청을 보내므로 계정 사용량이 발생합니다. Whisper·모델·FFmpeg·Codex 로그인이 준비되어 있어야 합니다.

실제 마이크 권한 승인·개인 녹음, 물리적인 장치 분리, 장시간 녹음, Intel Mac, 다른 사용자 계정은 이번 변경에서 직접 검증하지 않았습니다. 외부 배포용 Developer ID 서명·공증은 포함하지 않습니다.
